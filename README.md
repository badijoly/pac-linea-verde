# Dashboard de Evaluación · Línea Verde (PAC 2026)

Este repositorio contiene la aplicación web interactiva para la visualización, monitoreo y evaluación cuantitativa y cualitativa del aprendizaje de los participantes en la **Línea Verde** del **Programa de Acción Climática (PAC) 2026** en Antofagasta, Chile.

## 🌿 Desafíos Evaluados
- **Hito 3:** *"Los otros vecinos de Antofagasta"* (Biodiversidad costera, Humedal La Chimba, Gaviotín Chico y Cadenas Tróficas).
- **Hito 4:** *"Proteger nuestro escudo invisible"* (Atmósfera como regulador climático, contaminación lumínica y protección de cielos oscuros).

## 💡 Características Principales
- **Cálculo y Visualización en Navegador:** Funciona 100% en el cliente de forma autónoma.
- **Filtros Dinámicos Cruzados:** Por establecimiento, género, estado de avance (Mejoró, Mantuvo, Retrocedió) o búsqueda por participante.
- **Análisis de Preguntas y Distractores:** Estadísticas de aciertos pre vs. post y detección de errores conceptuales recurrentes.
- **Explorador Cualitativo:** Comparativa de respuestas abiertas y apropiación de vocabulario ecológico y científico.
- **Fichas Individuales:** Modal con el expediente detallado de cada estudiante.
- **Actualización Dinámica:** Botón para cargar cualquier archivo Excel (`.xlsx`) actualizado y recalcular métricas en vivo.
